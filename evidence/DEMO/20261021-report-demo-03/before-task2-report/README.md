## 이렇게 보고하면 됩니다

책임님, AMR의 상태 정보를 받고 이동·정지 같은 명령을 보내는 기본 통신 기능을 구현했습니다. 시험용 데이터를 보내 정상 수신과 잘못된 입력 처리를 확인했고, 통신 서버를 껐을 때 연결 이상을 알아채는지도 확인했습니다. 명령은 전달되는 단계까지 확인했으며, 이를 받아 가상 AMR이 실제로 움직이게 연결하는 부분은 다음 작업입니다.

실제 AMR 대신 시험용 데이터를 사용했습니다. 아래 내용은 그때 저장한 시험 결과입니다.

서버가 켜져 있어도 응답을 보내지 않는 상황을 추가로 만들었고, 이때도 프로그램이 이상을 알아채고 종료했습니다.

## 가상 AMR은 어디까지 됐나요?

설정 파일을 읽어 AMR의 이름과 처음 위치를 표시하는 기능은 확인했습니다. 시간이 지났을 때 어디로 이동해야 하는지 계산하는 부분도 자동시험으로 확인했습니다. 이 시험 당시 실행 프로그램은 초기 정보를 표시한 뒤 종료했습니다. 계속 움직이면서 통신 프로그램에 정보를 보내는 연결은 다음 작업입니다.

## 아직 남은 일

- AMR 한 대가 상태 정보를 보내지 않을 때 그 AMR을 찾아내기.
- 보낸 명령에 맞는 응답이 돌아왔는지 확인하기.
- 연결이 끊기면 프로그램이 자동으로 다시 연결하게 만들기.
- 가상 AMR의 이동 프로그램과 통신을 연결하고 명령대로 동작하게 만들기.

명령을 받았다는 사실과 실제 AMR이 움직였다는 사실은 따로 확인해야 합니다. 현재는 시험용 수신기까지 명령이 전달되는 것을 확인했습니다.
