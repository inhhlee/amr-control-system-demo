# 앞선 실행의 익명 볼륨 정리

첫 실행과 2차 실행에서 컨테이너 제거 후 남은 12개 익명 볼륨만 대상으로 한다. C1·C2의 마운트 기록, 부모 Broker의 Docker 목록에 기록된 마운트 이름(첫 실행은 유일하게 일치하는 접두사), C3의 정확한 container ID가 연결된 Docker mount 이벤트로 소유권을 대조한다. 생성 시각과 미사용 여부를 모두 확인한 뒤에만 제거한다. 전체 prune이나 force는 사용하지 않는다.

최초 사전 점검은 PowerShell의 날짜 자동 변환에 따른 시간대 차이로 중단됐다. 날짜를 문자열로 읽도록 수정한 다음 점검은 C3 마운트 기록 2개가 없는 것을 확인해 삭제 전에 중단됐다. 두 점검 모두 모든 검증이 끝나기 전이어서 삭제 호출은 없었다. C3 mount 이벤트를 추가 확보한 뒤 최종 `ownership.json`의 12개를 검증하고 정리한다. `commands.jsonl`은 이 점검·재실행 이력을 보존한다.

최종 판정은 `result.json`, 소유권은 `ownership.json`, 전후 전체 볼륨 목록은 `before.txt`·`after.txt`, C3 원본 근거는 `c3-volume-events.jsonl`에 있다. 이 정리는 이번 요청에서 생성한 자원에 한정하며 이전 작업의 남은 볼륨은 변경하지 않는다.
