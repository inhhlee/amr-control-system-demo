## 2026-11-01 정리 결과

[파일별 정리 목록](curation/20261101.json)에 원래 경로·작업 폴더 SHA256·Git blob·정리 이유·대체 결과/원본 URL을 기록했다. 과거 실행의 성공 TRX 32개, 전체 지도 상태 추적23개, 일회성 문서 도구1개는 정리 전 Git 커밋으로 연결했다. 로컬 빌드 생성물68개는 제거했다. 새 ZIP/복사본은 만들지 않았다.

파일 수는 **3,527 → 3,405개**, 용량은 **약168.67 → 106.66MB**로 줄었다. 원본을 고정 Git 버전으로 연결한56개와 로컬 생성물68개를 정리했고 색인·정리 목록2개를 추가했다. 이동/압축 복사본은 없다. 최종 바이트 수와 검사 결과는 위 정리 목록을 따른다.

고정 원본: [ae71f452 전체 evidence](https://github.com/inhhlee/amr-control-system-demo/tree/ae71f452f27a65ec2fee68fee60496a7a5ca3d6c/evidence). 이 버전은 원격 게시된 tree와 대조했다. 작업 폴더의 줄바꿈과 Git 저장 형식이 다를 수 있어 목록에 두 식별자를 구분한다.

과거 manifest의 파일 수·해시 목록과 당시 판정은 이력으로 보존했다. 그 목록에 있는 원본을 다시 검사하거나 과거 검증 도구를 실행하려면 고정 버전에서 자료를 복원해 사용한다. 현재 폴더에 모든 과거 원시 파일이 있다는 뜻으로 읽지 않는다. Git 과거 이력의 용량은 이번 정리로 줄어들지 않는다.

## 남겨 둔 자료와 한계

- 다른 실행 ID·코드 버전·시험 대역의 결과는 파일 이름이나 날짜만으로 합치지 않았다. 같은 실행의 후속 결과가 시험 이름을 모두 포함하는 정상 중간 TRX만 보관 위치를 바꿨다. 실패/중단과 첫 복구 결과는 유지했다.
- 같은 바이트의 컨테이너 전/후 기록은 서로 다른 시점의 관측이므로 역할이 다르다. 해시가 같다는 이유로 삭제하지 않았다.
- 기존 미추적 COM-01 결과 보기본35개는 사용자 작업으로 유지했다. 개별 시연·실패 원인을 확정하기 어려운 자료와 과거 감사 JSON은 보존했다.
- 문서 원본 과제3 계획에는 기존 병합 충돌 표시가 있다. 이번 파일 정리에서 문서 충돌을 해결하거나 상태를 추정하지 않았다.
- 이번 확인은 파일 정리·링크·해시·기존 완료 근거 보존 검사다. 제품 자동시험/MQTT/GUI를 새로 실행한 결과가 아니다. 커밋·푸시·PR은 별도 단계다.

앞으로는 실행마다 최종 요약·판정·재현 입력과 환경·필요한 대표 원본을 먼저 선정한다. 반복 정상 실행 전체 출력은 꼭 필요한 경우에 보관하며, 중요한 결함의 재현/수정 근거는 함께 남긴다.
