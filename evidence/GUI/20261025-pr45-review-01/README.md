## 확정 결함 1건

### P2: 지원하는 최소 창 크기에서 명령 결과 행이 잘림

- 위치: `src/Amr.ControlGui/MainForm.Designer.cs:106~109`의 명령 영역 행 배치. 같은 파일 179행은 최소 창 크기를 1000×720으로 지정한다.
- 조건: 최초 표시가 끝난 창을 1000×720으로 줄이고 명령 결과가 한 건 이상 존재한다.
- 입력: 장비 두 대, AMR_002의 MOVE 요청 한 건에 Mock 성공 결과를 부여한 전체 스냅샷.
- 예상: 명령 결과 행 한 줄을 온전히 읽을 수 있다.
- 실제: 표 높이 34px에서 머리글 26px을 제외하면 8px만 남는다. 25px 높이의 결과 행 중 8px만 표시된다. 성공/실패 텍스트와 요청별 정보를 읽을 수 없다.
- 근거: [verification.json](verification.json), [minimum-size.png](minimum-size.png).
- 수정 방향: 입력·안내에 고정 배정한 높이와 주변 배치를 조정하거나 명령 영역에 스크롤을 제공해 결과 행 높이를 보장한다. 최소 크기를 올리는 대안은 수정량이 작지만 작은 화면의 사용 가능 영역을 줄이므로, 현재 최소 크기 지원을 유지하려면 유연한 배치가 적합하다. 대안은 구현·성능 검증하지 않았다.
- 필요한 회귀 시험: 실제 초기 표시 이후 최소 크기로 변경하고 결과 한 건을 넣어, 머리글·스크롤바를 제외한 가시 높이가 결과 행 높이 이상인지 확인한다.
- 기존 시험 누락: `tests/Amr.ControlGui.Tests/DashboardMapTests.cs:117~135`는 요약 카드·장비 목록·지도만 확인하며 명령 결과 표는 확인하지 않는다.

- 기존 제품 시험: `../20261025-dashboard-map-06/README.md`의 953건 성공 기록을 검토했다. 이번 리뷰에서 전체 953건을 재실행하지 않았다.
