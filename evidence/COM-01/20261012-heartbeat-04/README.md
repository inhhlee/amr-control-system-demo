# 부분 결과와 시험 도구 재실행 오류

- UTF-8 콘솔 변경 후 빌드 경고/오류 0, 자동시험 18개 통과. [빌드·시험 종료 코드](build-test.json), [TRX](tests.trx).
- 첫 세션은 실제 Broker에서 입력 5건을 독립 관찰했고 C# 콘솔에는 Heartbeat 2건만 출력됐다. 비구독 Topic 3건은 진단 없음. Ctrl+C 정리·실제 프로세스 종료 0. [결과](mqtt-results.json), [콘솔](console-1.stdout.log), [관찰자](observer-1.stdout.log).
- 둘째 세션은 구독까지 확인했으나 시험 제어기 종료 1로 발행·정상 종료를 완료하지 못했다. 출력 손실로 상세 예외는 수집되지 않았다. 반복 Ctrl+C 제어를 같은 프로세스에서 처리하는 구조와 단일 입력 배열 취급을 보완한다.
- 소유한 시험 프로세스만 정리했다. [정리 로그](harness-failure.log). 두 세션 전체 통과로 집계하지 않는다.
- 최종 재시험: [05 기록](../20261012-heartbeat-05/README.md). 제품 소스는 04 빌드·자동시험 이후 변경하지 않았다.
