# COM03-C4 최초 빌드 — 환경 제한

2026-10-20 같은 `feature/6-mqtt-keepalive`에서 [사전 기준](criteria.json)과 [소스](source-version.json)를 저장하고 빌드했다. [build.log](build.log)의 MSB3491은 기존 시험 출력 폴더의 임시 파일 쓰기 권한 거부다. 빌드 종료 1이며 **시험은 실행하지 않았다**. 제품 결함·시험 통과로 집계하지 않는다.

소스 변경 없이 승인된 실행 환경에서 [unit-02](../20261020-c4-unit-02/README.md)로 재실행했다. 이 실행의 환경·명령·실패 로그는 보존한다.
