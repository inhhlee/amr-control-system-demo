## 게시 전 검토

- 수신/타이머/500ms 검사/연결 종료는 Communication 세션이 소유하며 기존 ID별 큐를 재사용한다. Core는 조립 어댑터가 변환한 관측을 받아 미션/경보를 처리한다. GUI는 Core 조회를 표시한다.
- AMR 단독 Timeout은 해당 미션만 보류한다. 복구는 경보를 해제하지만 명시적 재개 전까지 보류한다. Broker 단절 시 두 감시를 중지하며 마지막 Heartbeat/Telemetry를 보존하고 시연 제어를 거부한다. 보류는 차량의 물리 STOP이 아니다.
- 세션 ID·ID별 순번·미션 ID로 늦은 입력/이전 완료를 배제한다. 감시 관측은 큐 처리 전에 갱신하고 Core의 짧은 잠금 안에는 I/O가 없다. 이전 최소 창 시험 실패·ClientId 충돌·Broker 단절 후 제어 문제의 실패/수정/재시험 근거는 최종 검증 README에 보존했다.
- 기존 MQTT 접속 수정·Mock·최소 Core 계약·단일 AMR/F5 프로필·이전 시험은 유지한다. 새 Fleet 네이티브 F5·네이티브 재개 버튼 클릭·이번 정상 GUI 창 닫힘은 미검증이며 성공으로 표시하지 않는다.
