# 실제 좌표로 움직이는 2D 지도 시연

AMR 한 대가 **(-1, 0) 출발 → (1, 0) 경유 → (1, 2) 도착·정지**하는 모습을 보여주는 로컬 시연 도구다. 지도는 현재 콘솔과 같은 `SimulatorApplication.RunAsync`가 출력한 실제 좌표를 받는다. 브라우저에서 별도의 이동 계산이나 저장 로그 재생을 하지 않는다.

## 처음 실행하기

PowerShell에서 아래를 입력한다.

```powershell
Set-Location C:\amr-control-system-demo
dotnet run --project .\tools\Amr.Simulator.Map
```

`MapReady Url=http://127.0.0.1:5088 ...`가 나오면 [지도 열기](http://127.0.0.1:5088)를 누른다. **PowerShell 창은 켜 둔다.** 이미 5088 포트를 쓰고 있다면 `dotnet run --project .\tools\Amr.Simulator.Map -- --port 0`으로 실행하고 출력된 새 주소를 연다.

## 책임님께 보여드릴 순서

1. 지도에서 출발점 **(-1, 0)**, 경유점 **(1, 0)**, 목적지 **(1, 2)**를 짚는다.
2. **시연 시작**을 누른다. 청록색 점이 실제 좌표를 따라 움직이고, 오른쪽에 좌표·속도·상태가 바뀐다.
3. 약 4초 뒤 **도착·정지**, 좌표 **(1, 2)**, 속도 **0**, 상태 **IDLE**, 종료 코드 **0**을 보여준다.
4. 화면 아래 **실제 좌표의 근거·실행 로그**를 펼쳐 `AmrMoved`, `WaypointReached`, `SimulationCompleted`를 보여준다.
5. 다시 보여주려면 **다시 실행**을 누른다. 저장된 결과를 재생하는 것이 아니라 시뮬레이터를 새로 실행한다.

설명할 말:

> “이 점은 실제 시뮬레이터가 계산한 현재 위치입니다. 출발해서 경유점을 지나 목적지에 도착하면 멈춥니다. 오른쪽의 좌표와 속도, 아래의 실행 로그로 같은 결과를 확인할 수 있습니다.”

## 취소와 종료

- 이동 중 **실행 취소**: `SimulationCanceled`를 기록하고 해당 시뮬레이터 실행만 끝낸다. 지도는 마지막 계산 좌표를 유지하며 새 시연을 시작할 수 있다. 취소 로그의 BUSY·속도는 마지막 계산값이며 실제 로봇의 STOP 명령이 아니다.
- **지도 서버 종료**: 지도 서버를 실행한 PowerShell에서 **Ctrl+C**. 이동 중이면 시뮬레이터의 취소·종료를 기다린 뒤 서버를 끝낸다. 브라우저 탭을 닫는 것만으로 서버가 종료되지는 않는다.
- 서버 연결이 끊기면 화면에 **연결 끊김·마지막 수신 위치**가 표시된다. 이때 화면에 남은 좌표를 최신 상태로 해석하지 않는다.

## 설정을 바꿔 보여주기

다른 설정 파일을 지정하려면 서버를 종료한 뒤 다시 실행한다.

```powershell
dotnet run --project .\tools\Amr.Simulator.Map -- --config .\evidence\AMR\20261021-map-host-01\changed.json
```

이 예시는 (5, 3)에서 출발해 (5, 4)를 지나 (7, 4)로 이동하며 속도는 2m/s다. 도구는 서버를 시작할 때 설정 파일을 복사하고 검사한다. 지도 경로와 시뮬레이터가 같은 복사본을 사용하므로 파일을 편집했다면 서버를 다시 시작해야 한다. 기본 `config/simulator.single.json`은 변경하지 않는다.

## 결과는 어디에 남나

서버를 시작할 때 `evidence/AMR/map-live-날짜-고유번호/`를 만든다. 화면 아래에도 경로를 표시한다.

- `config.json`: 이번 서버가 사용하는 설정 복사본.
- `run-…stdout.log` / `stderr.log`: 실행마다 별도로 저장하는 실제 시뮬레이터 출력.
- `run-…result.json`: 해당 실행의 최종 좌표·상태·종료 코드·실행 ID.

웹 화면은 약 100ms마다 최신 좌표를 읽으며, 중간 갱신 일부를 건너뛸 수 있다. 전체 로그는 파일에 남긴다. 브라우저 표시 숫자는 소수 셋째 자리까지 반올림하고, 원본 좌표는 그대로 보관한다. 화면의 경과 시간은 실제 시뮬레이터가 기록한 값이다.

## 검증을 다시 실행하기

지도 서버를 먼저 실행하고, 별도 PowerShell에서 서버 주소를 지정한다. 이 검증은 실제 시뮬레이터를 반복 실행하므로 사용자 시연이 끝난 뒤 수행한다.

```powershell
pwsh -NoProfile -File .\tests\manual\AMR01\Verify-Map.ps1 -BaseUrl http://127.0.0.1:5088 -RunId ("map-api-" + (Get-Date -Format 'yyyyMMdd-HHmmss'))
pwsh -NoProfile -File .\tests\manual\AMR01\Verify-MapHost.ps1 -RunId ("map-host-" + (Get-Date -Format 'yyyyMMdd-HHmmss'))
```

두 번째 명령은 Windows에서 별도의 지도 서버를 시작해 설정 변경·이동 중 Ctrl+C·실제 종료를 검사하고 해당 서버만 정리한다. [이번 실제 검증 결과](../../evidence/AMR/20261021-map-01/README.md).

## 구현 범위

별도 `tools/Amr.Simulator.Map` 프로젝트가 현재 Simulator 프로젝트를 참조한다. 같은 서버 프로세스 안에서 실제 시뮬레이터를 실행하고 콘솔 출력을 수집하며, 웹 화면은 로컬 HTTP로 최신 상태를 읽는다. 제품의 설정·이동 계산·실행 루프 소스는 이번 작업에서 변경하지 않았다. 새 패키지와 솔루션 항목도 추가하지 않았다.

이 화면은 좌표 격자와 경로를 보여주는 시연 도구다. 건물 도면·장애물·충돌 회피·MQTT·실제 로봇·다중 AMR·과제3 전체 관제 GUI는 포함하지 않는다. 기본 경로와 변경 예시를 검증했으며 극단적인 좌표·대규모 경로·장시간·다중 사용자 운영 검증은 별도다.
